# 裁判計分系統

提供記分員使用的網頁計分工具。多位裁判打分數後，**去掉一個最高、一個最低，剩餘取平均**，並**無條件捨去至小數第三位**作為該選手成績。

🔗 線上使用：https://haze3161798.github.io/scoring/

## 功能

- 裁判人數可調整（預設 5，最少 3）
- 選手編號自動產生，姓名選填
- 每位選手「計算」即顯示成績，並標示被去掉的最高／最低分
- 「送出本組」將整組成績寫入側邊紀錄，輸入區清空準備下一組
- 資料存於瀏覽器 localStorage，重新整理不遺失
- 手機優先 RWD，桌機自動切雙欄

## 部署

純前端單一 `index.html`，零相依。直接由 GitHub Pages（main 分支、根目錄）託管。
